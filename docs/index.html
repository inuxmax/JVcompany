How it works

One request. A whole team on it.

The director turns your request into a hand-off chain. Each step starts automatically with the previous step's output; failures go back to the director, and you approve anything risky.

You→ CEO→ B1Studio→ B2Dev→ B3Test→ B4Fix Bug→ B5Test→ B6QA→ Report
  1. AskChat with the CEO, pick a project folder, paste screenshots.
  2. AssignThe tower CEO finds a free floor — or queues the project.
  3. PlanThe floor director scopes the work and builds the chain with per-step permissions.
  4. BuildDepartments work in your folder; results flow to the next step automatically.
  5. ReviewQA approves, the director reports, and you sign off on anything risky.

Quick start

Up and running in two minutes

You need Node.js 20+ and MongoDB (local or Atlas). Agent CLIs you have signed in to are detected automatically.

  • A 4-step setup creates your company, team and first project.
  • Prefer a desktop app? npm run desktop (Windows, macOS, Linux).
  • Listens on 127.0.0.1 only — your office stays private.
git clone https://github.com/inuxmax/JVcompany.git
cd JVcompany
npm install
cp .env.example .env.local   # set MONGODB_URI
npm run dev                  # http://127.0.0.1:2501

FAQ

Frequently asked questions

Is Văn Phòng AI free?

Yes. It is open source under the MIT license and runs on your own computer. You only pay for the AI you connect — or nothing with local models (Ollama, LM Studio) or subscriptions you already have.

Which AI models and coding agents are supported?

Claude Code, OpenAI Codex, Gemini CLI, Cursor Agent, GitHub Copilot CLI, Qwen Code, OpenCode and custom CLIs; API keys for Claude, OpenAI, Gemini, Grok, DeepSeek, OpenRouter, Groq, Mistral and any OpenAI-compatible endpoint; local models via Ollama and LM Studio.

Does my code leave my machine?

The app runs locally and binds to 127.0.0.1. Code is only sent to the AI provider you choose for a department — use a local model if nothing may leave your computer.

Can AI agents break my computer?

Every project and department has a permission level from read-only to full access. Anything above it becomes an approval request you must accept, and computer control is off until you enable it.

What happens when I hit a usage limit?

The run pauses, the reset time is read from the error, and the task resumes automatically — or switches to the department's fallback connection.
